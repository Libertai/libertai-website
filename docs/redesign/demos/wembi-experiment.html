( 07 ) · FAQAnswers up front
How do I know it is actually private?+
You do not have to take our word for it. Every model runs with nothing stored and nothing trained on you. For sensitive workloads, TEE-served models like Hermes 3 8B run inside hardware-sealed enclaves on Aleph Cloud's distributed network that even the node operator cannot inspect, with cryptographic attestation you can verify yourself.
Will my existing code work?+
Yes. The API is OpenAI-compatible: keep your SDK, change the base URL and key, and your code talks to LibertAI. Migration is one line, and the docs cover streaming, tool use and vision.
How does billing work?+
Two modes. Subscribe for a flat monthly price that covers steady usage, or buy credits and pay per million tokens. Usage past your subscription simply bills at the same per-token rate. No seats, no KYC.
What happens if a node goes down?+
Workloads reschedule across the network. Your endpoint is not one company's datacenter: it is a distributed pool of Aleph Cloud nodes, so no single machine, provider or jurisdiction can take it offline.
Which models can I run?+
GLM-5.2 leads, with open models behind the same endpoint: Qwen, Gemma, DeepSeek, Hermes and more, plus image generation, embeddings, speech and private web search. All open-weight, so nothing can be deprecated out from under you.
